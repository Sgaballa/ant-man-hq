# Ant-Man HQ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy "Ant-Man HQ" — a single-page Next.js fan site + live stats dashboard for Anthony Edwards and the Minnesota Timberwolves, hosted free on Vercel.

**Architecture:** Next.js 15 App Router, TypeScript, Tailwind CSS v4, Framer Motion for card-flip animations. All NBA data flows from balldontlie.io through server-side Next.js API routes (proxy pattern) that cache responses via `fetch` revalidate. Static page composition with client components only for interactive cards.

**Tech Stack:** Next.js 15, TypeScript, Tailwind CSS v4, Framer Motion, Vitest, Testing Library, `canvas-confetti`, balldontlie.io v1 API, Vercel.

**Spec:** `docs/superpowers/specs/2026-04-23-ant-man-hq-design.md`

`lib/balldontlie.ts`:

```ts
import type { ApiResponse } from "./types";

const BASE_URL = "https://api.balldontlie.io/v1";

type BalldontlieEnvelope<T> = { data: T };

export async function balldontlie<T>(
  path: string,
  init: { revalidate?: number } = {}
): Promise<ApiResponse<T>> {
  const apiKey = process.env.BALLDONTLIE_API_KEY;
  if (!apiKey) {
    return { ok: false, error: "BALLDONTLIE_API_KEY is not set", data: null };
  }

  try {
    const res = await fetch(`${BASE_URL}${path}`, {
      headers: { Authorization: apiKey },
      next: init.revalidate !== undefined ? { revalidate: init.revalidate } : undefined,
    });

    if (!res.ok) {
      return {
        ok: false,
        error: `balldontlie returned ${res.status}`,
        data: null,
      };
    }

    const json = (await res.json()) as BalldontlieEnvelope<T>;
    return { ok: true, data: json.data };
  } catch (err) {
    const message = err instanceof Error ? err.message : String(err);
    return { ok: false, error: message, data: null };
  }
}
```

`app/api/player/route.ts`:

```ts
import { NextResponse } from "next/server";
import { balldontlie } from "@/lib/balldontlie";
import {
  ANTHONY_EDWARDS_PLAYER_ID,
  CURRENT_SEASON,
} from "@/lib/constants";
import type { Player, SeasonAverage } from "@/lib/types";

export async function GET() {
  const [playerRes, avgRes] = await Promise.all([
    balldontlie<Player>(`/players/${ANTHONY_EDWARDS_PLAYER_ID}`, { revalidate: 86400 }),
    balldontlie<SeasonAverage[]>(
      `/season_averages?season=${CURRENT_SEASON}&player_ids[]=${ANTHONY_EDWARDS_PLAYER_ID}`,
      { revalidate: 3600 }
    ),
  ]);

  if (!playerRes.ok || !avgRes.ok) {
    return NextResponse.json({
      ok: false,
      error: (!playerRes.ok ? playerRes.error : avgRes.ok ? "" : avgRes.error) || "fetch failed",
      data: null,
    });
  }

  const seasonAverages = avgRes.data[0] ?? null;

  return NextResponse.json({
    ok: true,
    data: { player: playerRes.data, seasonAverages },
  });
}
```

```ts
import { NextResponse } from "next/server";
import { balldontlie } from "@/lib/balldontlie";
import { TIMBERWOLVES_TEAM_ID, CURRENT_SEASON } from "@/lib/constants";
import type { Game } from "@/lib/types";

export async function GET() {
  const res = await balldontlie<Game[]>(
    `/games?team_ids[]=${TIMBERWOLVES_TEAM_ID}&seasons[]=${CURRENT_SEASON}&per_page=100`,
    { revalidate: 300 }
  );

  if (!res.ok) {
    return NextResponse.json({ ok: false, error: res.error, data: null });
  }

  const todayIso = new Date().toISOString().slice(0, 10); // "YYYY-MM-DD"
  const games = [...res.data].sort((a, b) => a.date.localeCompare(b.date));

  const recent = games
    .filter((g) => g.date < todayIso && g.status === "Final")
    .slice(-5);

  const upcoming = games
    .filter((g) => g.date > todayIso)
    .slice(0, 5);

  const liveToday =
    games.find((g) => g.date === todayIso) ?? null;

  return NextResponse.json({
    ok: true,
    data: { recent, upcoming, liveToday },
  });
}
```

### Task 19: Compose homepage

**Files:**
- Modify: `app/page.tsx`

- [ ] **Step 1: Replace page.tsx**

We import the route handlers directly (they're just modules) and call them in-process. No HTTP round-trip, no base URL needed, no environment-dependent fallback. The `fetch` cache inside `lib/balldontlie.ts` still provides ISR via its `revalidate` option.

```tsx
// app/page.tsx

import { Header } from "@/components/Header";
import { HeroCard } from "@/components/HeroCard";
import { LiveGameWidget } from "@/components/LiveGameWidget";
import { StatsDeck } from "@/components/StatsDeck";
import { RecentGamesStrip } from "@/components/RecentGamesStrip";
import { ScheduleCarousel } from "@/components/ScheduleCarousel";
import { HighlightReel } from "@/components/HighlightReel";
import { Footer } from "@/components/Footer";
import { GET as getPlayerRoute } from "@/app/api/player/route";
import { GET as getGamesRoute } from "@/app/api/games/route";
import type { Game, Player, SeasonAverage } from "@/lib/types";

type PlayerResponse = { ok: boolean; data: { player: Player; seasonAverages: SeasonAverage | null } | null };
type GamesResponse = { ok: boolean; data: { recent: Game[]; upcoming: Game[]; liveToday: Game | null } | null };

export default async function Home() {
  const [playerRes, gamesRes] = await Promise.all([
    getPlayerRoute().then((r) => r.json() as Promise<PlayerResponse>),
    getGamesRoute().then((r) => r.json() as Promise<GamesResponse>),
  ]);

  const player = playerRes.ok && playerRes.data ? playerRes.data.player : null;
  const seasonAverages = playerRes.ok && playerRes.data ? playerRes.data.seasonAverages : null;
  const recent = gamesRes.ok && gamesRes.data ? gamesRes.data.recent : [];
  const upcoming = gamesRes.ok && gamesRes.data ? gamesRes.data.upcoming : [];
  const liveToday = gamesRes.ok && gamesRes.data ? gamesRes.data.liveToday : null;

  return (
    <main className="min-h-screen">
      <Header liveNow={!!liveToday} />
      <HeroCard player={player} seasonAverages={seasonAverages} />
      <LiveGameWidget liveToday={liveToday} upcoming={upcoming} />
      <StatsDeck seasonAverages={seasonAverages} />
      <RecentGamesStrip games={recent} />
      <ScheduleCarousel games={upcoming} />
      <HighlightReel />
      <Footer />
    </main>
  );
}
```
